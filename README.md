# 🍽️ Medtasty Menu

Welcome to the **Medtasty Menu** project!

This project is a simple HTML webpage built to showcase a fictional restaurant menu. It's designed as a beginner-level exercise to practice basic HTML skills including headings, lists, paragraphs, and links.

---

## 📌 Project Overview

The webpage includes:

- A clear and descriptive title
- Menu sections: **Appetizers**, **Main Courses**, and **Desserts**
- Each section contains an unordered list of three menu items
- Each menu item has a name and a short description
- A placeholder link to a contact page at the bottom
